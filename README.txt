NATURELIFE ANDROID PROJECT — v1.0

This is an Android Studio project that packages the current Naturelife prototype into a native Android WebView app.

Included:
- User's Naturelife logo
- Any Crop selection
- Add Any Crop
- GPS/manual location
- Planting date, land area and variety
- Smart crop timeline prototype

How to build the APK:
1. Install Android Studio on a computer.
2. Open this folder as an existing project.
3. Let Android Studio sync/download the Android Gradle Plugin and SDK.
4. Select Build > Build APK(s).
5. The debug APK will be under app/build/outputs/apk/debug/.

Note: This environment does not have the Android SDK/Gradle build tool installed, so the APK itself cannot be compiled here. The project is ready to build in Android Studio.
